# Gate change M01-2: G4 fixture pairs for members governed by patterns and open remainders

- Gate: M01-G4 (v1 stays additive)
- Files: `packages/contracts/test/__golden__/schema-diff/**`
- Raised by: independent review, round 2 ("Additive-only diff misses narrowing through
  new properties of records and open objects")

## Problem

The additive-only diff compared only the properties the old schema declared, so it
missed three narrowing shapes: `additionalProperties` going from `true` or absent to a
schema, a typed property added to an open object, and a named or pattern property
added to a record whose pattern already admitted that name with a wider type. No
fixture pair covered them, so G4 could not show they are detected.

Two existing fixture pairs encoded the missed case as harmless. In `additive` and
`new-required-new-property` the fixture `Step` object is open (no
`additionalProperties`) and gains a typed property (`note`, `owner`). A document valid
before could carry `note: 5`, which the new schema rejects, so the `additive` pair was
not additive and the `new-required-new-property` pair also narrowed a type.

## Change

- `additive` and `new-required-new-property`: the fixture `Step` object declares
  `additionalProperties: false` on both sides. The pairs keep testing what their notes
  say (a new optional property is additive; a new required property is reported) on
  the shape every published ARGUS object has (TypeBox closed objects).
- Four new pairs: `narrowed-type-open-additional` (Problem's open remainder becomes
  string-only), `narrowed-type-open-new-property` (Problem gains a typed optional
  member), `record-new-property` and `record-new-pattern` (the `variables` record gains
  a named boolean property or an overlapping boolean pattern; reported as
  `removed-variant`, because the old value schema is a union).

No threshold, count or coverage figure changes; the fixture count rises from 11 to 15
and every pair must still be detected exactly. The gate file and the G4 test are
unchanged.

## Verified

Before the implementation fix the four new pairs report no change and fail G4; the
two edited pairs pass both before and after it. After the fix all 15 pairs pass and the
comparison with the baseline and its history still finds no breaking change.
